# 🌸 E-Portfolio | นางสาวเปมิกา ศรีพยัคฆ์ (มิ้นท์)

> **"ยึดมั่นในสิ่งที่รัก อดทนกับสิ่งที่ทำ แล้วผลลัพธ์จะงดงามตามเวลาของมัน เปรียบเสมือนต้นไม้นานาที่กว่าจะออกดอก ที่ต้องอดทนผ่านฤดูหนาวที่ทรมาน"**

เว็บไซต์แฟ้มสะสมผลงานอิเล็กทรอนิกส์ (E-Portfolio) สำหรับยื่นสมัครเข้าศึกษาต่อในระดับอุดมศึกษา **คณะศิลปศาสตร์ สาขาวิชาภาษาญี่ปุ่นเพื่อการธุรกิจ มหาวิทยาลัยศรีปทุม (Sripatum University - SPU)**

---

## 👤 ข้อมูลผู้จัดทำ (Profile)

* **ชื่อ - นามสกุล:** นางสาวเปมิกา ศรีพยัคฆ์ (ชื่อเล่น: มิ้นท์)
* **สถานศึกษา:** โรงเรียนธัญรัตน์ จังหวัดปทุมธานี
* **ระดับชั้น / แผนการเรียน:** มัธยมศึกษาปีที่ 6/6 แผนการเรียนศิลป์ภาษาญี่ปุ่น
* **ผลการเรียนเฉลี่ยสะสม (GPAX):** `3.93` (ผลการเรียนกลุ่มสาระฯ ภาษาต่างประเทศ `4.00` และการศึกษาค้นคว้าด้วยตนเอง IS `4.00`)
* **เป้าหมายในอนาคต:** ล่ามภาษาญี่ปุ่น, ครูสอนภาษาญี่ปุ่น, นักการทูต

## 🎯 Statement of Purpose (โดยสรุป)

จุดเริ่มต้นความหลงใหลในภาษาญี่ปุ่นเกิดจากการรับชมอนิเมะในวัยเด็ก จนกระทั่งชั้นประถมศึกษาปีที่ 4 ได้เริ่มศึกษาประวัติความเป็นมาของภาษาญี่ปุ่นด้วยตนเอง และมุ่งมั่นสอบเข้าเรียนต่อที่โรงเรียนธัญรัตน์ในแผนการเรียนศิลป์-ภาษาญี่ปุ่น ด้วยความอดทนและการยึดมั่นในเป้าหมายอย่างจริงจัง ทำให้สามารถพัฒนาทักษะทางภาษาและวัฒนธรรมญี่ปุ่นได้อย่างต่อเนื่อง พร้อมต่อยอดความรู้ด้านภาษาญี่ปุ่นเพื่อการธุรกิจในระดับอุดมศึกษา

## 🏮 กิจกรรมและประสบการณ์เด่น (Activities)

* **เทศกาลวันทานาบาตะ (Tanabata Festival) ปีการศึกษา 2567 – 2569:** เติบโตจากบทบาทผู้บรรยายและนักแสดง สู่ผู้ดูแลการฝึกซ้อมและการจัดสรรงานเบื้องหลัง รวมถึงรับหน้าที่ออกแบบการ์ดเชิญอย่างเป็นทางการมอบให้คณะผู้บริหารและครูผู้สอน
* **ตัวแทนเปิดขบวนวัฒนธรรมญี่ปุ่น:** ได้รับคัดเลือกเป็นตัวแทนนำเปิดขบวนธีม *"งานแต่งจิ้งจอก" (Kitsune no Yomeiri)* สวมบทบาทเป็น Xiao Miko ฝึกฝนการแต่งหน้าและคอสเพลย์ด้วยตนเอง พร้อมกำกับรูปแบบขบวน
* **กิจกรรมพัฒนาผู้เรียนด้านวัฒนธรรมญี่ปุ่น:** เข้าร่วมการจัดดอกไม้สไตล์ญี่ปุ่น (Ikebana), เกมพื้นบ้านญี่ปุ่น (Fukuwarai) และการเขียนการ์ดอวยพรปีใหม่ญี่ปุ่น (Nengajo)

## 💻 โครงสร้างโปรเจกต์เว็บไซต์ (Project Structure)

เว็บไซต์นี้พัฒนาขึ้นด้วย **HTML5, CSS3 และ Vanilla JavaScript** ภายในไฟล์เดียว (`index.html`) โดยไม่ต้องติดตั้งไลบรารีเพิ่มเติม ออกแบบด้วยธีมสีชมพูซากุระ-ชมพูบานเย็นตามอัตลักษณ์ของคณะศิลปศาสตร์ มหาวิทยาลัยศรีปทุม และรองรับการแสดงผลทุกขนาดหน้าจอ (Responsive Design)

```text
📁 pemika-portfolio/
├── 📄 index.html        # โค้ดหลักของเว็บไซต์ E-Portfolio (HTML + CSS + JS)
├── 📄 README.md         # เอกสารแนะนำโครงงานและประวัติย่อ
└── 📁 images/           # โฟลเดอร์เก็บรูปภาพประกอบ (หากต้องการเพิ่มรูปภาพจริง)

    ├── infographic.jpg  # รูปผลงาน Infographic ซากุระ
